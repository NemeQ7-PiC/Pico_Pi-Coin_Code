# 🚀 PI-Coin Pico Miner

**Small device. Big mining ambitions! ⛏️**

Welcome to the PI-Coin Pico Miner project! This project brings PI-Coin mining to the Raspberry Pi Pico W and Raspberry Pi Pico 2W.

## 🔌 Supported Hardware

- Raspberry Pi Pico W
- Raspberry Pi Pico 2W
- More in the future...

## ✨ Features

- 📡 Wi-Fi connectivity
- ⛏️ PI-Coin mining support
- 🔋 Low-power operation
- 🔄 Automatic restart every 6 hours
- 📊 Mining statistics
- 🌐 Connection to the PI-Coin mining infrastructure
- 📦 Compact and affordable hardware
